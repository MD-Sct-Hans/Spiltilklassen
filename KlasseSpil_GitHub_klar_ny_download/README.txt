KLASSESPIL - GRATIS SPILPORTAL (TESTVERSION)
========================================

LOKALT:
1. Pak zip-filen ud.
2. Åbn index.html i Chrome eller Edge.
3. Klik 'Spil nu' på et af spillene.
4. Alle spil er selvstændige HTML-filer og kan downloades enkeltvis.

UDGIV GRATIS VIA GITHUB PAGES:
1. Opret en konto på github.com, hvis du ikke allerede har en.
2. Opret et nyt PUBLIC repository, fx klassespil.
3. Upload alle filer og mapper fra denne zip til roden af repository.
   Behold mappestrukturen assets/ og spil/.
4. Under Settings > Pages, vælg Deploy from a branch, main og /(root).
5. Gem. GitHub viser herefter den offentlige adresse.

UDGIV VIA CLOUDFLARE PAGES:
1. Opret en Cloudflare-konto.
2. Under Workers & Pages, opret et Pages-projekt med Direct Upload.
3. Upload den udpakkede mappe.
4. Cloudflare giver en offentlig .pages.dev-adresse.

VIGTIGT:
- Navnet 'KlasseSpil' er kun et foreløbigt arbejdsnavn. Undersøg om navnet kan bruges før offentlig lancering.
- Denne udgave bruger ingen tredjepartsbiblioteker eller sporing.
- Hostingudbydere kan dog føre serverlogs og behandle IP-adresser.
- Husk korrekt beskrivelse af privatliv og kontaktoplysninger før lancering.
- Afprøv især grafiske koordinater og svarknapper på smartboard.
- Alle filerne må ændres og tilpasses efter behov.
